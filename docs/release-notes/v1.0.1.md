### Image Studio: a free image converter and ICO maker for Windows
- **Converter**: drop in files or whole folders and convert them to JPG, PNG, WEBP, AVIF, TIFF, GIF, ICO, PDF or 100+ other formats in one go. iPhone photos (HEIC), RAW camera files, PSD and SVG can be read too, and every PDF page can become its own image. Results go into a subfolder by default, so your originals stay safe.
- **ICO Maker**: paste a picture with **Ctrl+V** (or drag it in), frame it, round the corners, and export a crisp, multi-size `.ico` for Windows apps or websites.

English and Vietnamese, works offline, no ads, no account, no tracking. ImageMagick is built in; only PDF files need the free [Ghostscript](https://ghostscript.com/releases/gsdnld.html).

### What's new in 1.0.1
- The **Converter** is now the main tool: it comes first and the app opens on it.

### Which file should I download?
- **`ImageStudio-Setup-1.0.1.exe`**: the installer. The easy choice; no admin rights needed.
- **`ImageStudio-Portable-1.0.1-win-x64.zip`**: the portable version. Unzip it anywhere and run `Image Studio.exe`.

Already using Image Studio? **About → Check for updates** in the app finds new versions.
